# ⚪ LUMEN 3D — Real-Time Spatial Intelligence Platform

A high-end 3D SaaS website engineered with **pure white & porcelain brand aesthetics**, **real-time Three.js WebGL 3D graphics**, and **spatial micro-interactions**.

---

## 🌟 Key Features

1. **Pure White & Porcelain Aesthetic**:
   - Radiant white foundation (`#ffffff`) with subtle porcelain and pearlescent gradients.
   - Deep obsidian and titanium typography with sharp contrast.
   - Minimalist micro-borders (`border-black/[0.06]`) and frosted white glass panels (`backdrop-blur-xl`).

2. **Real-Time Interactive 3D WebGL Viewport (Three.js)**:
   - Central interactive **Geodesic Torus Knot** sculpture with orbital planetary rings and floating particle nebula.
   - **Interactive Mouse Tracking**: Damped inertia that smoothly tracks cursor position across the screen.
   - **Drag-to-Rotate**: Grab and freely spin the 3D geometry in 3D space.
   - **Interactive 3D Material / Shader Switcher**:
     - 🪞 **Liquid Titanium**: High-specular reflective metalness.
     - 💎 **Frosted Crystal**: Refractive translucent glass.
     - ⚡ **Quantum Wireframe**: Minimalist technical wireframe geometry.

3. **Interactive 3D Spatial Cards**:
   - Bento grid cards with dynamic 3D perspective tilt on hover (`perspective: 1000px`).

4. **Compute & ROI Calculator**:
   - Clean porcelain sliders for Engineering Scale and 3D Mesh Throughput.
   - Instant dynamic calculations for Annual Hardware Savings and Render Fidelity (120 FPS).

5. **Multi-Language Code Sandbox**:
   - Language switcher (TypeScript, Python, cURL) with 1-click clipboard copy and toast notification.

6. **Transparent White Pricing**:
   - Annual discount toggle with animated price switches.
